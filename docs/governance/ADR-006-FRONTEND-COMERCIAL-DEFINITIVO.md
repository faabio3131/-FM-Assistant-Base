# ADR-006 — Frontend comercial definitivo

**Data:** 2026-10-17  
**Status:** APPROVED

## Contexto

O produto ainda não possui painel Web comercial. A Fundação Nova FM proíbe construir UI descartável conhecida de antemão.

## Decisão

O próximo frontend será a **linha comercial final** e evoluirá incrementalmente até acabamento premium.

Escopo mínimo:

- onboarding;
- persona;
- knowledge;
- integrações;
- WhatsApp;
- inbox humano;
- CRM;
- pipeline;
- follow-up;
- equipe/RBAC;
- analytics;
- uso/plano/billing;
- configurações.

## Consequências

- Proibido criar painel técnico provisório para depois migrar.
- Design system e acessibilidade entram desde a fundação.
- Backend permanece autoridade.
- Secrets nunca entram no browser.
